# Sklep

Desktop clothing shop application built with **JavaFX** and **PostgreSQL**.

> Work in progress.

## Roles

- **Guest** – browse the catalogue, log in or register
- **Client** – browse products, manage the cart, place and track orders
- **Administrator** – manage products, categories, users and orders

## Tech stack

- Java 21, JavaFX 23 (FXML + Scene Builder)
- PostgreSQL, JDBC
- Maven

## Running

Requirements: JDK 21+.

```bash
./mvnw clean javafx:run      # Linux / macOS
mvnw.cmd clean javafx:run    # Windows
```

## Conventions

- Source code (classes, methods, variables, database) is written in **English**.
- User interface texts are in **Polish**.
